# Deployment terms

Each operator must publish their own service identity, contact details and terms before offering this Activity to others. This file describes the software's intended use and does not name a universal operator.

Use only media you are authorized to access and share. Follow the hosting operator's rules and the terms of Discord, Audiobookshelf and any identity provider. Do not attempt to access another person's saved connection, bypass media permissions or misuse the community account.

Playback depends on server capacity, codecs, network conditions and Discord/device support. The software does not guarantee availability, background playback or uninterrupted synchronization. Operators may limit access or end sessions to address misuse, capacity or security issues.

The source software is supplied under its included licenses. Report vulnerabilities privately to the repository maintainer or deployment operator without disclosing credentials or accessing other users' data.
