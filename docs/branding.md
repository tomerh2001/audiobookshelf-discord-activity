# Branding

The application name is **Audiobookshelf Listen**. Operators can change their Discord application name, icon and description without embedding a particular server or guild in the software. Native Audiobookshelf artwork and license attribution remain with the packaged client.

Do not reuse Jellyfin logos or advertise unsupported native group playback. This Activity synchronizes Audiobookshelf's native player through its own room coordinator. Registration and documentation use `/listen` and **Listen to Audiobookshelf**.
